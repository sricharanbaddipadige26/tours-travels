# 🚖 Shikara Tours & Travels

A modern and responsive car rental & travel booking website built using HTML, CSS, and JavaScript. The website allows users to explore available vehicles, contact drivers, book rides through WhatsApp, and provides an easy-to-use interface for travel services.

## 🌟 Features

- 🏠 Attractive Home Page
- 🚗 Vehicle Listing Section
- 👨‍✈️ Driver Details with Contact Information
- 💬 WhatsApp Booking Integration
- 📱 Fully Responsive Design
- ⚡ Smooth Navigation
- 🎨 Modern UI/UX
- 📍 Contact Information
- 💳 Payment Integration (Coming Soon)

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome Icons

## 🚀 How to Run

1. Clone the repository

```bash
git clone https://github.com/your-username/Shikara-Tours-Travels.git
```

2. Open the project folder

```bash
cd Shikara-Tours-Travels
```

3. Open `index.html` in your browser.

Or use the VS Code **Live Server** extension.
